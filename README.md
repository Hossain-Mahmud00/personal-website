# Hossain Mahmud Personal Website

A modern, responsive personal portfolio website built with plain HTML, CSS, and JavaScript.

## Features

- Clean hero section and personal branding
- About, projects, skills, experience, and contact sections
- Mobile-friendly responsive layout
- Modern dark aesthetic with accessible contrast
- Lightweight and easy to customize

## Run locally

Open `index.html` in a browser, or serve it with any static web server.

Example:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

## Customize

Update the content in `index.html` to add your real:

- name and headline
- bio and project details
- email, GitHub, and LinkedIn links
- experience and skills

## Deploy

This site can be deployed to GitHub Pages, Netlify, Vercel, or any static hosting provider.
